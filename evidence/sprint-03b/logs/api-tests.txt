======================================================================
SENTINEL-TRACE V5 — SPRINT 3B API ENDPOINT VERIFICATION LOG
======================================================================
Tested Endpoints on http://localhost:8000/api/v1:

1. POST /api/v1/normalized-events/{normalized_event_id}/interpret
   - Input: Valid normalized event ID
   - Response Code: 200 OK
   - Payload: interpretation_id, status, policy_id, vendor_name, source_field, source_value, canonical_field, interpreted_value, equivalence_classification, risk_level, confidence_score, explanation, drift_alerts
   - Idempotency: Verified (second identical request returns cached record)

2. GET /api/v1/semantic-interpretations
   - Query Params: status=INTERPRETED, risk_level=LOW, vendor_name=Cisco Systems, page=1, page_size=20
   - Response Code: 200 OK
   - Payload: Array of interpretations, total count, page, page_size

3. GET /api/v1/semantic-interpretations/{interpretation_id}
   - Input: Valid interpretation ID (e.g., interp_20b79f325b4842e7)
   - Response Code: 200 OK
   - Payload: Full record with child drift_alerts

4. GET /api/v1/semantic-interpretations/{interpretation_id}/trace
   - Input: Valid interpretation ID
   - Response Code: 200 OK
   - Payload: Full audit chain:
     * raw_evidence: event_id, filename, source_name, raw_content, raw_payload_hash, integrity_verified
     * normalized_event: normalized_event_id, ocsf_class_uid, canonical_payload, confidence
     * source_profile: source_profile_id, profile_name, format_type
     * vendor_context: vendor_name, source_profile_id
     * semantic_policy: policy_id, policy_name, vendor_name, version, status
     * policy_rule: rule_id, source_field, source_value, target_canonical_value, classification
     * interpretation: interpretation_id, status, confidence_score, risk_level, explanation
     * drift_alerts: array of attached alerts

5. GET /api/v1/semantic-drift-alerts
   - Query Params: severity=MEDIUM, status=ACTIVE, drift_type=UNMAPPED_VALUE, page=1, page_size=20
   - Response Code: 200 OK
   - Payload: Array of drift alerts with pagination metadata

6. GET /api/v1/semantic-drift-alerts/{alert_id}
   - Input: Valid alert ID
   - Response Code: 200 OK
   - Payload: Full alert record
