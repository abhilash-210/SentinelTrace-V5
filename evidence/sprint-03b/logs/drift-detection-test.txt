1. Drift Type: UNMAPPED_VALUE
- Trigger: Source event contains a semantic token not covered by any active vendor policy rule.
- Example: Cisco ASA event with action = 'UNKNOWN_CUSTOM_OP'
- Status Assigned: UNMAPPED
- Severity: MEDIUM
- Risk Level: MEDIUM
- Confidence Deduction: -0.50 (Final: 0.50)
- Generated Alert: alert_unmapped_01
- Action Recommended: Create vendor policy rule proposal for unmapped token in next policy lifecycle cycle.

----------------------------------------------------------------------
2. Drift Type: AMBIGUOUS_MAPPING
- Trigger: Active vendor policy classifies source value mapping as AMBIGUOUS.
- Example: Demo Vendor event with action = 'PERMIT' -> canonical 'MONITORED'
- Status Assigned: AMBIGUOUS
- Severity: MEDIUM
- Risk Level: MEDIUM
- Confidence Deduction: -0.25 (Final: 0.60/0.75)
- Generated Alert: alert_ambig_01
- Action Recommended: Operator review of vendor semantics in observation mode.

----------------------------------------------------------------------
3. Drift Type: PROTECTED_FIELD_RISK
- Trigger: Semantic interpretation targets a protected security field (e.g., authentication.outcome, action.result) with AMBIGUOUS or INCOMPATIBLE classification.
- Example: Demo Vendor auth_status = 'PASS' -> authentication.outcome = 'CHALLENGED' (AMBIGUOUS)
- Status Assigned: AMBIGUOUS
- Severity: HIGH
- Risk Level: HIGH
- Additional Confidence Deduction: -0.15
- Generated Alert: alert_prot_01
- Action Recommended: Immediate governance review required. Risk of authentication bypass or silent auth misclassification.

----------------------------------------------------------------------
4. Drift Type: POLICY_CONFLICT
- Trigger: Multiple conflicting active rules produce inconsistent canonical interpretations for the same token.
- Example: Rule A maps ALLOW -> ALLOWED, Rule B maps ALLOW -> DENIED within the same policy.
- Status Assigned: CONFLICT
- Severity: HIGH
- Risk Level: HIGH
- Confidence Overridden to: 0.00
- Generated Alert: alert_conflict_01
- Action Recommended: Block downstream pipeline ingestion. Require dual-control administrative resolution of policy conflict.

----------------------------------------------------------------------
5. Drift Type: INCOMPATIBLE_MAPPING
- Trigger: Rule explicitly designated as INCOMPATIBLE equivalence classification.
- Severity: HIGH
- Risk Level: HIGH
- Confidence Deduction: -0.40
- Generated Alert: alert_incompat_01
